Creator-controlled live interactions

Bring TikTok LIVE gifts into Minecraft.

Shakyfinity is a desktop companion that lets a streamer connect TikTok LIVE gift events to custom commands on a Minecraft server they control.

Shakyfinity is an independent project and is not affiliated with, endorsed by, or sponsored by TikTok, ByteDance, or Minecraft/Mojang Studios. TikTok LIVE event support uses an unofficial third-party connector and may change when TikTok updates its services.

What Shakyfinity does

Connect a LIVESign in with TikTok Login Kit, then connect the public username of the LIVE account.
Configure interactionsCreate gift triggers and select the Minecraft command to run.
Connect MinecraftUse the ServerTap plugin on a compatible server that you own or administer.

Data and control

Shakyfinity is designed to run locally on the creator's computer. TikTok authorization and ServerTap connection details are held in memory while the app is running. Interaction settings are stored in the browser on that device. See the Privacy Policy and Terms of Service for details.

This website describes the Shakyfinity desktop companion. The application is currently in development.
